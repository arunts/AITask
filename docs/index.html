A Mac app for local models

Bare-bones tasks for local models.

A task is the smallest set of instructions that gets a job done: what to do, and the inputs to ask for. AITaskRunner sends the model exactly that and nothing else, so small models running on your Mac stay on track. Save the tasks you repeat and run them again, on demand or on a schedule.

Why bare-bones

No bloat, on purpose.

Local models have small context windows and lose the thread when they are crowded. A task keeps the context to what you wrote.

Only your instructions

A system prompt for the standing rules and a user prompt for the job. There is no hidden framework prompt wrapped around them.

Only the inputs it needs

Name the values the task should ask for, such as a piece of text, a file or a folder, and the app asks for them before each run.

Only your Mac

Runs on Ollama, LM Studio, llama.cpp, vLLM or Apple's on-device model. No accounts, no analytics, nothing sent anywhere.

How it works

Define once, run again.

Add a model

Point the app at any OpenAI-compatible server on your Mac or your network. On Apple silicon the on-device model is there without setup.

Write a task

A few lines of instructions and the inputs to ask for. Or import a task file someone else wrote.

Run it

Fill in the inputs, pick a model, run it. Tasks you want repeated can run every few hours while the app is open.

A task is one small file

This is the whole task.

A name, the standing rules, the job, and the inputs to ask for. Export it as JSON, share it, import it on another Mac.

The AITaskDefinition specification covers every field. The ai-task-author skill teaches Claude Code, Codex and other coding agents to write task files for you.

Read the spec Get the skill 
{
  "format": "AITaskDefinition",
  "version": 1,
  "task": {
    "name": "Rewrite for Clarity",
    "systemPrompt": "You are a plain-English editor. Keep the meaning, cut the words.",
    "userPrompt": "Rewrite the text below. Reply with the rewritten text only.\n\n{{text}}",
    "variables": [
      { "key": "text", "type": "text", "description": "The text to rewrite" }
    ]
  }
}

Task repository

Ready-made tasks

Each one is a JSON file: download it and import it into the app.

Summarise Notes Folder

Reads every Markdown and text file at the top of a folder and writes a SUMMARY.md next to them: one paragraph overall, then two sentences per file.

Files & foldersWriting

Find PII in Folder

Goes through the PDFs, scans and office documents in a folder one at a time and finds the personal details in each that are yours, guided by a PII list it grows as you confirm items. Asks once per document about anything doubtful.

Extract Key Details from Folder

Reads each document in a folder and saves your details plus its key dates, amounts and reference numbers, grouped under the issuing organisation, into a plain-text list. Runs unattended and skips duplicates.

Convert Documents to Markdown

Turns every PDF, scan, image and office document in a folder into a Markdown file that keeps each word and the whole structure: headings, lists, tables, page markers and placeholders for figures. Needs a vision model.
