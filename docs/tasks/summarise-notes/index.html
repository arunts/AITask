Summarise Notes Folder

Reads every Markdown and text file at the top of a folder and writes a SUMMARY.md next to them: one paragraph overall, then two sentences per file.

2 variablesFiles & foldersWriting

System prompt

Sent before the user prompt on every run
You are a concise technical writer. Always read files with shell__run before summarising; never guess contents. Only run commands that read, plus the single write in the final step. Reply in Markdown.

User prompt

Sent each run with the variables filled in
1. Run shell__run with: find "{{notes_folder}}" -maxdepth 1 \( -name '*.md' -o -name '*.txt' \) | head -n {{max_files}} 2. For each file listed, run shell__run with: head -c 20000 "<path>" 3. Write a Markdown summary: a one-paragraph overview, then one bullet per file with its name in bold and two sentences about it. 4. Save it by running shell__run with: cat > "{{notes_folder}}/SUMMARY.md" <<'EOF' <the summary> EOF 5. Reply with only the sentence: "Wrote SUMMARY.md covering N files."

The app asks for these before each run. Defaults are pre-filled; the values you last used are remembered.
